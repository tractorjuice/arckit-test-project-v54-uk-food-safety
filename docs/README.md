# UK Food Safety - Documentation

This project uses **ArcKit v6.22.1** with the UK food safety overlay (`arckit-uk-food`).

## Getting Started

Run the overlay's commands in this order:

- `/arckit-uk-food:uk-food-profile` - the business profile
- `/arckit-uk-food:uk-food-safe-methods` - one section of safe methods at a time
- `/arckit-uk-food:uk-food-own-methods` - the business's own methods
- `/arckit-uk-food:uk-food-check` - what is finished and what is not
- `/arckit-uk-food:uk-food-sign-off` - a named person signs a finished document

See the [ArcKit documentation](https://arckit.org) for the full command reference.
